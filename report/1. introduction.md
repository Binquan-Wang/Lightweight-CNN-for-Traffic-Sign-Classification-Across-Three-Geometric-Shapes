# 1. Introduction

## 1.1 Background

Traffic sign recognition is an important application of computer vision. It is widely used in intelligent transportation systems and driver assistance technologies. Correctly recognising traffic signs can help drivers understand road conditions and improve road safety.

Convolutional Neural Networks (CNNs) are commonly used for image classification because they can automatically learn visual features such as shapes, colours and patterns. However, training neural networks can require considerable computational resources, especially when the dataset becomes larger.

This project investigates the performance and scalability of a lightweight CNN for traffic sign classification.

## 1.2 Dataset and Problem Description

The project uses the German Traffic Sign Recognition Benchmark (GTSRB). The original dataset contains more than 50,000 traffic sign images across 43 categories (Stallkamp et al., 2011).

To reduce the computational workload, this project focuses on three traffic sign categories:

- **Priority Road (Class 12):** A diamond-shaped sign indicating priority on the road.
- **No Entry (Class 17):** A circular sign indicating that vehicles are not allowed to enter.
- **Children Crossing (Class 28):** A triangular warning sign indicating that children may be crossing the road.

These categories were selected because their geometric shapes are visually different. This makes them suitable for investigating whether a relatively simple CNN can learn useful features for image classification.

Although the three signs have different meanings, the model aims to identify the correct traffic sign category rather than simply recognise geometric shapes.

## 1.3 Research Question

**How accurately can a lightweight CNN classify three traffic signs with different geometric shapes, and how does increasing the dataset size affect training time, computational efficiency and scalability?**

## 1.4 Project Objectives

The main objectives of this project are:

1. To prepare and explore a three-class traffic sign image dataset.
2. To develop a lightweight CNN using Python and PyTorch.
3. To evaluate classification performance using Accuracy, Macro F1-score and a Confusion Matrix.
4. To compare training time and model performance across different dataset sizes and batch sizes.
5. To discuss how the model and data-processing pipeline could be adapted to handle a dataset 1,000 times larger.

## 1.5 Project Scope

This project focuses on image classification rather than traffic sign detection. The input images already contain individual traffic signs, so the CNN will only need to predict which of the three categories each image belongs to.

The project will use a simple CNN architecture to keep training costs manageable. The main focus is not to achieve the highest possible accuracy, but to investigate the relationship between classification performance and computational efficiency.

The scalability analysis will use experiments on smaller datasets to discuss potential challenges when processing significantly larger amounts of image data.
